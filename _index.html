Apa itu Python?

Kelebihan Python

  • Sintaks sederhana dan mirip bahasa manusia

  • Data science & machine learning (NumPy, Pandas, TensorFlow)
  • Automasi dan scripting
  • Game development (Pygame)

Materi 2: Variabel & Tipe Data

Variabel

Wadah untuk menyimpan data

nama = "Budi"
umur = 16
tinggi = 175.5

Aturan Penamaan Variabel

  • Boleh huruf, angka, underscore (_)
  • Harus dimulai dengan huruf atau underscore
  • Tidak boleh ada spasi
  • Gunakan snake_case (nama_lengkap)
  • Hindari kata kunci Python

Tipe Data Dasar (1/2)

Integer (bilangan bulat)

umur = 16
saldo = -5000

Float (bilangan desimal)

tinggi = 175.5
phi = 3.14159

Tipe Data Dasar (2/2)

String (teks)

Boolean (True/False)

Materi 4: Perulangan

Perulangan For dengan Range

for i in range(1, 6):
    print(i)

Output: 1 2 3 4 5

  • range(5) → 0,1,2,3,4
  • range(1, 6) → 1,2,3,4,5
  • range(0, 10, 2) → 0,2,4,6,8

Perulangan While

counter = 1

while counter <= 5:
    print(counter)
    counter = counter + 1

Output: 1 2 3 4 5

⚠️ Jangan lupa increment counter!

Break dan Continue

Break: Keluar dari loop

for i in range(1, 11):
    if i == 5:
        break
    print(i)  # Output: 1 2 3 4

Continue

for i in range(1, 6):
    if i == 3:
        continue
    print(i)  # Output: 1 2 4 5

Nested Loop

for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} x {j} = {i*j}")
    print()

Program: Hitung Jumlah 1-N

n = int(input("N: "))
jumlah = 0

for i in range(1, n + 1):
    jumlah = jumlah + i

print(f"Jumlah 1 sampai {n} = {jumlah}")

Contoh: N=5 → 1+2+3+4+5 = 15

Materi 6: Fungsi

Konsep Fungsi

def sapa():
    print("Halo, selamat datang!")

sapa()  # Panggil fungsi

Fungsi dengan Parameter

def sapa(nama):
    print(f"Halo, {nama}!")

sapa("Budi")  # Halo, Budi!
sapa("Ani")   # Halo, Ani!

Fungsi dengan Return

def tambah(a, b):
    hasil = a + b
    return hasil

jumlah = tambah(5, 3)
print(jumlah)  # 8

print(tambah(10, 20))  # 30

Banyak Parameter & Return

def hitung_persegi(panjang, lebar):
    luas = panjang * lebar
    keliling = 2 * (panjang + lebar)
    return luas, keliling

l, k = hitung_persegi(10, 5)
print(f"Luas: {l}, Keliling: {k}")

Default Parameter

def sapa(nama="Teman"):

Materi 8: Proyek Mini

Proyek 1: Manajemen Nilai Siswa

Fitur:

  • Tambah siswa
  • Lihat semua siswa
  • Cari siswa
  • Hitung rata-rata
  • Hapus siswa

Proyek 1 - Struktur

siswa = []

def tambah_siswa():
    nama = input("Nama: ")
    nilai = int(input("Nilai: "))
    siswa.append({"nama": nama, "nilai": nilai})

def lihat_semua():
    for i, s in enumerate(siswa):
        print(f"{i+1}. {s['nama']}: {s['nilai']}")

def hitung_rata_rata():
    if len(siswa) > 0:
        total = sum(s["nilai"] for s in siswa)
        rata = total / len(siswa)
        print(f"Rata-rata: {rata:.2f}")

Proyek 2: Game Tebak Angka

Fitur:

  • Komputer pilih angka random (1-100)
  • User menebak dengan 10 kesempatan
  • Feedback: terlalu besar/kecil
  • Hitung jumlah tebakan

Proyek 2 - Kode

import random

angka_rahasia = random.randint(1, 100)
kesempatan = 10
tebakan = []

while kesempatan > 0:
    tebakan_user = int(input(f"Tebak (sisa {kesempatan}): "))
    
    if tebakan_user == angka_rahasia:
        print(f"BENAR! {len(tebakan)} tebakan")
        break
    elif tebakan_user < angka_rahasia:
        print("Terlalu KECIL")
    else:
        print("Terlalu BESAR")
    
    kesempatan -= 1
