Program 1 – Cek Ganjil / Genap

Seleksi + for

Mengecek beberapa bilangan apakah ganjil atau genap.

Program meminta jumlah data, lalu membaca setiap angka dan menampilkan apakah angka tersebut bilangan ganjil atau genap menggunakan operator modulo.

# Program 1: Cek Ganjil / Genap (seleksi + for) print("=== Program 1: Cek Ganjil / Genap ===") n = int(input("Berapa banyak angka yang ingin dicek? ")) for i in range(n): angka = int(input(f"Masukkan angka ke-{i+1}: ")) if angka % 2 == 0: print(f"{angka} adalah bilangan genap") else: print(f"{angka} adalah bilangan ganjil")

Program 2 – Total dan Rata-Rata Nilai

While + if + continue

Menghitung total dan rata-rata dari data nilai yang dimasukkan.

Siswa memasukkan nilai berulang kali sampai mengetik kata stop, nilai negatif diabaikan dengan continue, lalu program menghitung total dan rata-rata.

# Program 2: Total dan Rata-Rata Nilai (while + if + continue) print("=== Program 2: Total dan Rata-Rata Nilai ===") total = 0 jumlah_data = 0 while True: teks = input("Masukkan nilai (atau 'stop' untuk selesai): ") if teks.lower() == "stop": break # keluar dari loop nilai = int(teks) if nilai < 0: print("Nilai tidak boleh negatif!") continue # lompat ke iterasi berikutnya total += nilai jumlah_data += 1 if jumlah_data > 0: rata = total / jumlah_data print(f"Total nilai = {total}") print(f"Rata-rata = {rata:.2f}") else: print("Tidak ada data nilai yang valid.")

Program 3 – Persegi Angka

Nested loop

Mencetak pola persegi berisi angka dari 1 sampai n.

Program ini menggunakan dua for bersarang untuk mencetak persegi n × n, di mana setiap baris berisi urutan angka dari 1 hingga n.

# Program 3: Persegi Angka (nested for) print("=== Program 3: Persegi Angka ===") n = int(input("Masukkan ukuran persegi: ")) for i in range(n): # loop baris for j in range(n): # loop kolom print(j + 1, end=" ") print() # ganti baris

Program 4 – Segitiga Bintang Naik

Nested loop

Mencetak segitiga bintang dengan tinggi tertentu.

Program menggambar segitiga kanan ke bawah dengan jumlah bintang per baris bertambah dari 1 sampai n menggunakan nested loop.

# Program 4: Segitiga Bintang (nested for) print("=== Program 4: Segitiga Bintang ===") n = int(input("Masukkan tinggi segitiga: ")) for i in range(1, n + 1): # baris for j in range(i): # jumlah bintang per baris print("*", end="") print()

Program 5 – Tabel Perkalian

Nested loop + formatting

Menampilkan tabel perkalian rapi sampai bilangan n.

Program menggunakan nested loop dan format string dengan lebar 4 karakter agar kolom hasil perkalian rata dan mudah dibaca.

# Program 5: Tabel Perkalian (nested loop + formatting) print("=== Program 5: Tabel Perkalian ===") n = int(input("Tampilkan tabel perkalian sampai: ")) for i in range(1, n + 1): for j in range(1, n + 1): hasil = i * j print(f"{hasil:4}", end="") # lebar 4 karakter biar rapi print()
