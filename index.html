Materi 1 – Pengenalan & Instalasi

Level: Pemula

Mengenal Python dan menyiapkan lingkungan kerja.

1.1 Apa itu Python?

Python adalah bahasa pemrograman tingkat tinggi yang mudah dibaca, fleksibel, dan banyak dipakai untuk berbagai keperluan (web, data, AI, automasi, game, dan lain-lain). [file:1]

  • Sintaks sederhana dan mirip bahasa manusia. [file:1]
  • Cross-platform (Windows, Mac, Linux) dan komunitas sangat besar. [file:1]

1.2 Instalasi Python

  1. Buka python.org/downloads. [file:1]
  2. Unduh Python 3.x sesuai sistem operasi. [file:1]
  3. Jalankan installer, centang Add Python to PATH, lalu klik Install. [file:1]
  4. Cek di terminal: python --version. [file:1]

1.3 Editor & Environment

  • IDLE (bawaan Python) dan Thonny cocok untuk pemula. [file:1]
  • VS Code, PyCharm, dan Jupyter Notebook populer untuk proyek yang lebih serius. [file:1]

1.4 Menjalankan Program Python

  • Interactive shell (REPL): ketik python lalu jalankan per baris. [file:1]
>>> print("Hello, World!") Hello, World!
  • File .py: simpan file lalu jalankan dengan python nama_file.py. [file:1]

1.5 Program Pertama

# hello.py # Ini adalah komentar print("Hello, World!") print("Nama saya adalah Python")

Tips: Gunakan komentar # untuk menjelaskan bagian kode pada siswa. [file:1]

Materi 2 – Variabel & Tipe Data

Kunci dasar

Menyimpan data, mengenal tipe data, dan membaca input.

2.1 Variabel

Variabel adalah wadah untuk menyimpan nilai, misalnya nama, umur, atau tinggi badan. [file:1]

nama = "Budi" umur = 16 tinggi = 175.5
  • Nama variabel diawali huruf atau underscore, tanpa spasi. [file:1]
  • Gunakan gaya snake_case seperti nama_siswa. [file:1]

2.2 Tipe Data Dasar

  • Integer: bilangan bulat, misalnya umur = 16. [file:1]
  • Float: bilangan desimal, misalnya tinggi = 175.5. [file:1]
  • String: teks, misalnya nama = "Budi". [file:1]
  • Boolean: True atau False. [file:1]

2.3 Operator Aritmatika & Perbandingan

a = 10 b = 3 # Aritmatika print(a + b) # 13 print(a // b) # 3 (pembagian bulat) print(a % b) # 1 (sisa bagi) # Perbandingan print(a > b) # True print(a == b) # False

2.5 Input & Konversi Tipe Data

nama = input("Masukkan nama Anda: ") print("Halo, " + nama) umur = int(input("Berapa umur Anda: ")) print(umur + 1)

Penting: input() selalu mengembalikan string, gunakan int() atau float() untuk konversi numerik. [file:1]

2.7 Contoh: Kalkulator Sederhana

angka1 = float(input("Masukkan angka pertama: ")) angka2 = float(input("Masukkan angka kedua: ")) jumlah = angka1 + angka2 kurang = angka1 - angka2 kali = angka1 * angka2 bagi = angka1 / angka2 print("\n--- Hasil Perhitungan ---") print(f"Penjumlahan: {jumlah}") print(f"Pengurangan: {kurang}") print(f"Perkalian : {kali}") print(f"Pembagian : {bagi}")

Materi 3 – Percabangan

If / Elif / Else

Membuat keputusan dalam program.

3.1 Operator Logika

x = 5 print( (x > 0) and (x < 10) ) # AND umur = 15 print( (umur < 12) or (umur > 18) ) # OR is_admin = False print( not is_admin ) # NOT

3.2–3.4 If, If-Else, If-Elif-Else

skor = int(input("Masukkan skor Anda: ")) if skor >= 70: print("Anda LULUS") else: print("Anda TIDAK LULUS")
nilai = int(input("Masukkan nilai Anda (0-100): ")) if nilai >= 90: print("Grade: A") elif nilai >= 80: print("Grade: B") elif nilai >= 70: print("Grade: C") elif nilai >= 60: print("Grade: D") else: print("Grade: E")

3.5–3.6 Contoh Program

Gunakan percabangan bersarang untuk aturan yang lebih kompleks, misalnya izin berkendara dan penilaian huruf. [file:1]

Materi 4 – Perulangan

For & While

Mengulang instruksi secara otomatis.

4.1 Perulangan For dengan Range

for i in range(1, 6): print(i) # 1 sampai 5
  • range(5) → 0,1,2,3,4. [file:1]
  • range(0, 10, 2) → 0,2,4,6,8. [file:1]

4.2 While & Infinite Loop

counter = 1 while counter <= 5: print(counter) counter = counter + 1

Hati-hati: Jangan lupa menaikkan counter, kalau tidak akan terjadi infinite loop. [file:1]

4.3 Break & Continue

for i in range(1, 11): if i == 5: break print(i) # 1 2 3 4 for i in range(1, 6): if i == 3: continue print(i) # 1 2 4 5

Materi 5 – List & String

Koleksi data

Mengelola kumpulan data dan teks.

5.1–5.3 List

buah = ["apel", "pisang", "jeruk"] print(buah[0]) # apel print(len(buah)) # 3 buah.append("mangga") buah.remove("pisang")

5.4–5.5 Iterasi & Slicing

angka = [1, 2, 3, 4, 5] print(angka[1:4]) # [2, 3, 4] print(angka[::2]) # [1, 3, 5]

5.6–5.7 String & Metode

teks = "hello world" print(teks.upper()) print(teks.replace("world", "Python")) kata = teks.split(" ") print(kata) print(" ".join(kata))

Materi 6 – Fungsi

Modularisasi

Membagi program menjadi blok-blok yang dapat dipakai ulang.

6.1–6.3 Fungsi Dasar

def sapa(nama): print(f"Halo, {nama}!") sapa("Budi") sapa("Ani")
def tambah(a, b): hasil = a + b return hasil print(tambah(5, 3))

6.4–6.6 Parameter, Return, Scope

Gunakan parameter untuk mengirim data ke fungsi dan return untuk mengembalikan hasil perhitungan. [file:1]

Variabel di luar fungsi bersifat global, sedangkan variabel di dalam fungsi hanya bisa dipakai di fungsi tersebut. [file:1]

6.7 Contoh: Kalkulator Geometri

Program menghitung luas dan keliling persegi, serta luas lingkaran menggunakan fungsi terpisah. [file:1]

Materi 7 – Tuple, Set, Dictionary

Tipe data lanjut

Struktur data untuk kebutuhan yang lebih spesifik.

7.1 Tuple

warna = ("merah", "hijau", "biru") for w in warna: print(w)

7.2 Set

angka1 = {1, 2, 3, 4, 5} angka2 = {4, 5, 6, 7, 8} print(angka1.union(angka2)) print(angka1.intersection(angka2)) print(angka1.difference(angka2))

7.3–7.5 Dictionary

siswa = { "nama": "Budi", "umur": 16, "kelas": "10A" } print(siswa["nama"]) siswa["nilai"] = 85
